## 📱 О приложении

XMSLEEP — это профессиональное приложение для воспроизведения белого шума и природных звуков, созданное для улучшения вашего сна и концентрации. Приложение включает множество тщательно подобранных природных звуков: дождь, гром, костёр, пение птиц и многое другое.

## ✨ Возможности

### 🎵 Аудио функции
- **Множество звуков**: дождь, костёр, гром, мурлыканье кошки, птицы, сверчки и другие природные звуки
- **Онлайн аудио**: динамическая загрузка аудиоресурсов с GitHub
- **Локальное аудио**: воспроизведение аудиофайлов с вашего устройства
- **Бесшовный цикл**: непрерывное зацикленное воспроизведение
- **Регулировка громкости**: индивидуальная настройка громкости для каждого звука
- **Сохранение настроек**: громкость автоматически сохраняется и восстанавливается
- **Bluetooth гарнитура**: автоматическая пауза при отключении гарнитуры
- **Bilibili радио**: поиск и воспроизведение прямых эфиров Bilibili, возможность закреплять избранные комнаты

### 🎨 Интерфейс
- **Анимации**: встроенные звуки сопровождаются WebP анимацией
- **Material Design 3**: современный дизайн
- **Переключение тем**: светлая/тёмная тема, адаптация к системной теме
- **Пользовательские темы**: выбор цветовых тем, поддержка динамических цветов

### ⚙️ Полезные функции
- **Таймер**: установка времени автоматической остановки
- **Пресеты**: 3 пресета для быстрого переключения между наборами звуков
- **Избранное**: сохранение любимых звуков
- **Недавние**: быстрый доступ к недавно воспроизводившимся звукам
- **Плавающая кнопка**: отображение текущих звуков, быстрая пауза
- **Автообновление**: проверка обновлений через GitHub Releases

### 🌐 Веб-версия
- **Онлайн-плеер**: работает сразу в браузере — 113 природных звуков, свободное микширование, бесшовный цикл, индивидуальная громкость
- **Многоязычность**: китайский/английский/японский/корейский/русский/традиционный китайский
- **Таймер обратного отсчёта**: пользовательский отсчёт с автостопом и отображением времени в реальном времени
- **Панель воспроизведения**: просмотр/остановка/регулировка громкости активных звуков
- **Оптимизация загрузки**: предзагрузка первого экрана + LRU-кэш для мгновенного повтора

## 🛠️ Технологии

- **Kotlin** - основной язык
- **Jetpack Compose** - UI фреймворк
- **Material Design 3** - дизайн-система
- **ExoPlayer/Media3** - аудиодвижок
- **OkHttp** - сетевые запросы
- **Gson** - JSON парсинг
- **Kotlinx Serialization** - JSON сериализация
- **Coil** - загрузка изображений
- **WebP** - анимации
- **MaterialKolor** - генерация цветов
- **Accompanist** - Pull-to-refresh
- **Hilt** - фреймворк внедрения зависимостей
- **Lottie** - высококачественный рендеринг анимации
- **Web Audio API** - бесшовный цикл в веб-версии (точность до сэмпла)

### 🆕 Последнее обновление (v2.3.3)

#### 🎨 Новые функции
- **Случайный фон для «Цитаты дня»**: фон диалога теперь использует случайную ежедневную обоину Bing (только кэш в памяти, без записи на диск); текст выровнен по низу с затемнением для читаемости; постер «поделиться/сохранить» тоже использует этот рисунок
- **Фильтр чувствительных слов**: цитаты автоматически блокируют слова о самоповреждении/тяжёлой негативности (например, суицид, депрессия); при совпадении в API выполняется повтор, локальные цитаты пропускаются

#### ✨ Улучшения
- **Диалог «Цитаты дня»**: закреплён на 2/3 высоты экрана, длинный текст прокручивается; значок обновления перенесён вверх-вправо со скруглёнными углами

### 🆕 Последнее обновление (v2.3.2)

#### 🎨 Новые функции
- **Источник QWeather (BYOK)**: погода теперь поддерживает пользовательский ключ QWeather (Host + Key в настройках), при отсутствии — авто-фоллбэк на Open-Meteo; городское определение местоположения + многоязычность

#### ✨ Улучшения
- **Карточка погоды**: город и дата объединены в одну строку (напр. «上海市 8月25日 Tuesday») и размещены над утешительной фразой; значок источника удалён
- **Смещение координат**: преобразование WGS84 → GCJ02 для точности локализации в Китае

### 🆕 Последнее обновление (v2.3.1)

#### 🎨 Новые функции
- **Веб-версия онлайн-плеера**: добавлена веб-версия на GitHub Pages — 113 природных звуков, свободное микширование, бесшовный цикл, интерфейс на 6 языках, список звуков синхронизирован с приложением, установка не требуется
- **Вход в веб-версию из приложения**: в модуле «Другое» настроек добавлен пункт «Веб-версия» — переход в онлайн-плеер одним нажатием и копирование ссылки
- **Чёрно-белая тема**: добавлена монохромная тема в минималистичном стиле
- **Фоновый таймер томато**: отсчёт продолжается после выхода со страницы, шкала показывает длительность текущего этапа
- **Карточная панель настроек томато**: карточная панель + прослушивание звука окончания + регулировка длительности перерыва
- **Управление медитацией из уведомлений**: управление воспроизведением медитации из шторки уведомлений/экрана блокировки
- **Локализация множественного числа**: корректные формы множественного числа для счётчиков (plurals) в английском, русском и других языках

#### ✨ Улучшения
- **Ужесточение разрешений**: сокращены объявления разрешений для снижения рисков приватности
- **Firebase аналитика и отчёты о сбоях**: анонимная статистика и сбор сбоев — личная информация не собирается

#### 🐛 Исправления

- Регистрация службы дыхания, локализация уведомлений

### 🆕 Последнее обновление (v2.3.0)

#### 🎨 Новые функции
- **Звук окончания томато-таймера**: 4 встроенных рингтона без лицензии (Колокольчик/Динь-дон/Маримба/Колокольчики), автоматическое воспроизведение по завершении фокуса
- **Вибрация окончания томато-таймера**: автоматическая вибрация по завершении фокуса, настраивается в настройках
- **Панель настроек томато**: шестерёнка в правом верхнем углу — выбор звука окончания, анимации завершения и вибрации, панель полностью разворачивается

- **Вход в томато в режиме погоды**: добавлен ярлык томато-таймера в правом верхнем углу погодного режима

#### ✨ Улучшения
- **Многоязычность настроек томато**: поддержка китайского/английского/японского/корейского/русского/традиционного китайского

## 🔨 Сборка

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/Tosencen/XMSLEEP.git
   cd XMSLEEP
   ```

2. **Настроить Gradle**
   - Скопировать `gradle.properties.example` в `gradle.properties`
   - (Опционально) Настроить GitHub Token

3. **Открыть проект**
   - Открыть проект в Android Studio
   - Синхронизировать Gradle

4. **Запустить**
   - Подключить устройство или запустить эмулятор
   - Нажать кнопку запуска

## 📖 Инструкция

### Основы
1. **Воспроизведение**: нажмите на карточку звука для запуска
2. **Громкость**: нажмите на иконку громкости для регулировки
3. **Таймер**: установите время автоматической остановки

### Интерфейс
4. **Тема**: кнопка переключения темы в левом верхнем углу
5. **Настройки**: цвета темы, анимации и другие параметры
6. **Пресеты**: добавление звуков в пресет через заголовок карточки
7. **Переключение пресетов**: в нижней области пресетов
8. **Избранное**: через заголовок карточки звука
9. **Bilibili радио**: нажмите кнопку поиска на странице радио для поиска комнат Bilibili по категориям, нажмите на иконку булавки, чтобы закрепить часто используемые комнаты

### Продвинутые функции
10. **Плавающая кнопка**: отображается при воспроизведении звуков
11. **Массовое добавление**: в развёрнутом состоянии плавающей кнопки
12. **Автоскрытие**: при прокрутке или переключении вкладок
