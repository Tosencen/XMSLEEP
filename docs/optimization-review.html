P2 工具链版本偏旧，kapt 拖慢构建
AGP 8.7.3 / Kotlin 2.1.0 / Compose BOM 2024.12.01 均为 2024 年底的组合。 Hilt 仍走 kapt（Hilt 2.48+ 已支持 KSP），换 KSP 通常能明显加快增量编译——在上面 P1 决定 Hilt 去留时一并处理。

建议：分两步升级，先 AGP+Gradle，再 Kotlin+Compose BOM，每次升完跑全量构建。
P2 两条打包配置与"减小 APK 体积"的目标自相矛盾
代码注释明确写了"只保留 arm64-v8a 以减小 APK 体积"，但下面两条配置在往反方向使劲： useLegacyPackaging = true 会让 so 以未压缩形式打包；keepDebugSymbols 保留调试符号。 （注释说明这是为规避 strip 警告，属权宜之计，但确实在付出体积代价。）
