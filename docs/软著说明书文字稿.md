### 1.2 软件简介

「晓满助眠冥想软件」是一款面向睡眠障碍人群与冥想爱好者的移动端应用。软件以"助眠、放松、冥想、专注"为核心，集成白噪音播放、在线助眠电台、呼吸练习、冥想引导、番茄专注时钟、翻页时钟、心情日记、天气智能推荐等多项功能，帮助用户在入睡、休息、学习工作时获得宁静与专注的体验。

软件采用 Jetpack Compose 声明式 UI 框架开发，支持动态取色主题、多语言（简体中文、繁体中文、英文、日文、韩文、俄文）、深浅色模式，并针对手机竖屏场景进行深度优化。

### 1.3 运行环境

- 硬件环境：支持 Android 8.0 及以上系统的智能手机，建议内存 4GB 以上，需具备网络连接能力
- 软件环境：Android 8.0（API 26）及以上操作系统，使用所需权限包括：
  - 网络权限：在线音频、电台、天气与更新等联网功能
  - 音频读取权限（Android 13 及以上为 READ_MEDIA_AUDIO，更低版本为 READ_EXTERNAL_STORAGE）：从本机音乐库导入音频
  - 定位权限（ACCESS_COARSE_LOCATION，粗略定位，可选）：天气智能推荐功能
  - 通知权限（Android 13 及以上）：前台播放通知与播放控制
  - 安装权限：软件内自动更新安装新版本

## 二、软件安装与启动

### 2.1 安装

用户可通过应用商店下载安装包（APK 文件），或通过第三方分发渠道获取安装包。安装时授予应用所需的网络、存储等权限后即可完成安装。

## 三、功能介绍

### 3.1 白噪音页面

白噪音页面是软件的核心页面之一，提供丰富的助眠声音卡片，用户可点击播放任意声音并自由混音。

主要功能包括：
1. **声音播放**：内置雨声、流水、风声、海浪、鸟鸣、篝火、城市等众多白噪音音源，点击卡片即可播放，支持多声音同时播放混音；
2. **混音控制**：每个正在播放的声音可独立调节音量，也可一键全部静音；
3. **预设功能**：默认提供 3 组预设场景，用户可将常用声音组合收藏到预设中并自定义预设名称，一键播放整套声音；
4. **智能倒计时**：支持设置自动停止倒计时（30/45/60/120 分钟等），到点自动停止所有声音，适合睡前使用；
5. **天气智能推荐**（可选功能）：开启后可获取当地天气，软件根据天气状况（如雨天、雷雨天、晴夜）自动推荐与之匹配的助眠声音，并在页面顶部展示天气卡片；
6. **每日一句**：页面顶部展示治愈系每日格言，点击可查看往期语录；
7. **快捷播放栏**：屏幕底部悬浮播放按钮，可快速控制所有声音的播放、暂停与混音，拖动可吸附到屏幕边缘。

（图：白噪音页面截图）

### 3.2 繁星页面

繁星页面提供远程助眠音频资源的浏览、在线试听与下载。

主要功能包括：
1. **分类浏览**：音频资源按自然、雨声、城市、场所、交通、物品、噪音、动物等分类展示，支持多语言分类名称；
2. **在线试听**：点击音频卡片即可在线播放，支持缓存到本地；
3. **离线下载**：可将音频下载到本地，支持批量管理与存储空间查看，离线时仍可播放；
4. **天气联动**：音频资源同样参与天气智能推荐；
5. **本地音频入口**：支持从本机音乐库导入音频（需授予存储权限），导入后可与其他白噪音一起混音播放。

（图：繁星页面截图）

### 3.3 电台页面（可选）

电台页面提供在线电台播放功能：

1. **电台列表**：展示可用的电台频道，点击播放在线音频流；
2. **播放控制**：支持播放/暂停、音量调节、缓冲状态提示；
3. **定时关闭**：支持设置播放倒计时，到点自动停止；
4. **悬浮气泡**：电台播放时显示悬浮气泡，可拖拽，点击气泡快速控制播放。

该页面可在"设置-特色功能"中隐藏。

（图：电台页面截图）

### 3.4 呼吸与冥想页面（可选）

呼吸与冥想页面包含两部分：

1. **呼吸练习**：内置多种呼吸引导法（如 478 睡眠呼吸法、4-4-4-4 等），跟随动画引导吸气和呼气节奏，辅助放松入睡；
2. **冥想引导**：提供多分类、多时长的冥想音频课程，支持在线播放、定时关闭，辅助用户进行正念冥想练习。

该页面可在"设置-特色功能"中隐藏。

（图：呼吸与冥想页面截图）

### 3.5 设置页面

设置页面提供全面的应用配置管理，按类别分组：

1. **外观设置**：
   - 主题与颜色：支持浅色/深色/跟随系统三种模式，内置多款主题色，支持动态取色（跟随壁纸颜色）；
   - 背景设置：可设置应用背景（无背景/星空动画背景/自定义图片背景），支持调整背景透明度与模糊度；
   - 特色功能：开关"启动时显示最近播放""开启应用自动播放""电台 Tab""呼吸 Tab"等。
2. **系统设置**：
   - 翻页时钟：进入翻页时钟页面，可设置倒计时与字体；
   - 天气智能推荐：开关天气联动推荐功能（需定位权限）；
   - 自动倒计时：设置所有声音播放的默认自动停止时长；
   - 语言：支持简体中文、繁体中文、英文、日文、韩文、俄文六种语言切换。
3. **其他**：
   - 每日一句：查看全部往期语录与每日格言；
   - 日记：查看收听历史与每周收听汇总；
   - 加入群聊：进入用户交流社群；
   - 请我喝咖啡：支持对软件进行捐赠支持；
   - 关于：查看版本信息与更新检测。

（图：设置页面截图）

### 3.6 翻页时钟页面

翻页时钟页面提供翻页式大时钟显示：

1. **翻页时钟**：以翻牌动画显示当前时间，背景透明可叠加动画背景；
2. **倒计时**：支持设置倒计时并显示剩余时间；
3. **字体选择**：支持切换数字字体；
4. **自动旋转**：支持传感器自动旋转横竖屏；
5. **常亮显示**：进入页面后屏幕保持常亮，适合作为床头时钟使用；4 秒无操作自动收起操作栏。

（图：翻页时钟页面截图）

### 3.7 番茄时钟页面

番茄时钟页面提供专注计时功能：

1. **专注计时**：支持设置专注时长（刻度尺滑动选择），开始专注倒计时；
2. **正弦波进度环**：以动态正弦波环形动画展示专注进度，波形随进度逐渐平缓；
3. **自动休息**：专注结束后自动进入休息倒计时，无需手动操作；
4. **呼吸脉冲边框**：计时期间屏幕边缘呈现轻柔呼吸效果的脉冲边框，营造沉浸氛围；
5. **完成统计**：记录今日完成的番茄数。

（图：番茄时钟页面截图）

### 3.8 心情日记页面

心情日记页面记录用户的收听历史：

1. **收听历史**：按时间展示用户播放过的声音与时长；
2. **每周汇总**：自动统计本周收听数据，生成收听时长汇总；
3. **清空记录**：支持一键清空全部历史记录。

（图：心情日记页面截图）

## 四、软件亮点

1. **助眠功能全面**：集白噪音、电台、冥想、呼吸、翻页时钟、番茄时钟于一体，覆盖入睡、休息、专注全场景；
2. **多声音混音**：支持多音源同时播放并独立调音，打造个性化睡眠环境；
3. **天气智能联动**：依据实时天气自动推荐匹配的助眠声音，体贴自然；
4. **深度个性化**：动态主题色、自定义背景、六种语言、可隐藏 Tab，高度可定制；
5. **离线可用**：支持音频缓存与本地音乐导入，无网络时亦可使用；
6. **隐私友好**：全部数据本地保存，不上传用户个人信息。

### 主要功能与技术特点（申请表填写建议）

「晓满助眠冥想软件」是一款面向睡眠障碍人群与冥想爱好者的 Android 移动应用。软件以"助眠、放松、冥想、专注"为核心，主要功能包括：

1. **白噪音混音播放**：内置雨声、流水、风声、海浪、鸟鸣、篝火等大量助眠音源，支持多音源同时播放、独立调音与一键静音，并支持自定义预设组合一键播放；
2. **远程音频与离线缓存**：统筹管理海量分类助眠音频（自然、雨声、城市、动物等），支持在线试听、下载缓存离线播放，并可从本机音乐库导入音频混音；
3. **在线助眠电台**：提供多频道在线电台流播放，支持播放控制、定时关闭与悬浮气泡操控；
4. **呼吸与冥想引导**：内置多种呼吸练习法并配套动画引导，同时提供多分类冥想音频课程，支持在线播放与定时停止；
5. **番茄专注时钟**：提供可视化正弦波进度环的专注计时，支持自动休息与完整统计；
6. **翻页时钟**：翻牌动画大时钟，支持倒计时、字体切换与常亮显示，可作床头时钟；
7. **天气智能推荐**：依据获取的天气状况自动推荐匹配的助眠声音组合；
8. **深度个性化**：动态取色主题、自定义动画/图片背景、浅深色模式与多语言（简中、繁中、英、日、韩、俄）。

技术特点：采用 Kotlin + Jetpack Compose 声明式 UI 构建；基于 AndroidX Media3（ExoPlayer）实现多路音频混音与前台媒体播放服务（MediaSession 集成，支持通知栏与系统媒体卡片控制）；全量音频缓存与本地存储管理；数据全部本地保存，不上传用户个人信息。
